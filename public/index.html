Accès à votre machine virtuelle

Pi-Lo peut afficher votre console VM si vous configurez une passerelle distante sécurisée, par exemple Apache Guacamole ou noVNC derrière HTTPS.

Ne publiez jamais directement VNC, RDP ou SSH sur Internet. Protégez la passerelle par HTTPS et une authentification dédiée.
Passerelle distante configuréeOuvrir dans un nouvel onglet ↗

Si le bureau ne s'affiche pas dans ce cadre, utilisez le nouvel onglet. La passerelle doit autoriser l'intégration en iframe.

Aucune URL de bureau configurée. Ajoutez VM_CONSOLE_URL dans votre fichier .env puis redémarrez Pi-Lo.

Démarrage rapide

  1. Copiez .env.example vers .env et définissez un secret et un hash de mot de passe.
  2. Lancez npm install puis npm start.
  3. Pour l'accès distant, utilisez un VPN ou un reverse proxy HTTPS avec authentification.
  4. Pour la VM, configurez Apache Guacamole/noVNC séparément puis définissez VM_CONSOLE_URL.
