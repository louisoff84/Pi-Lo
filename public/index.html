Pi-Lo peut afficher votre console VM si vous configurez une passerelle distante sécurisée.

Installation et bonnes pratiques.

Démarrage rapide

  1. Copiez .env.example vers .env et définissez un secret et un hash de mot de passe.
  2. Lancez npm install puis npm start.
  3. Pour l'accès distant, utilisez un VPN ou un reverse proxy HTTPS avec authentification.
  4. Pour le bureau distant, configurez noVNC séparément puis définissez VM_CONSOLE_URL.
